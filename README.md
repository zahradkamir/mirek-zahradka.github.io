# Žijte naplno – Mirek Zahrádka

Osobní webové stránky.

## Publikování přes GitHub Pages
1. Na GitHubu vytvořte veřejný repozitář.
2. Nahrajte všechny soubory z této složky.
3. V **Settings → Pages** zvolte **Deploy from a branch**, větev `main` a složku `/ (root)`.
4. GitHub následně zobrazí adresu publikovaného webu.
